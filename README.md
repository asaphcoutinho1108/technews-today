# 📰 TechNews Today - Portal de Tecnologia

## 📋 Sobre o Projeto

O **TechNews Today** é uma página web criada como atividade de desenvolvimento utilizando **HTML e CSS**.

O projeto simula um portal de notícias sobre tecnologia, apresentando uma notícia em destaque, vídeo, formulário de newsletter e informações de contato.

O objetivo foi praticar conceitos de **HTML semântico, formulários, organização de conteúdo e estilização com CSS**.

---

## 🎯 Objetivo

Desenvolver uma página moderna e responsiva utilizando HTML e CSS, aplicando os conhecimentos aprendidos durante as aulas.

O projeto busca apresentar informações de tecnologia de maneira organizada, simples e visualmente agradável.

---

## 💻 Tecnologias Utilizadas

- 🌐 HTML5
- 🎨 CSS3
- 📱 Design responsivo
- 🧩 HTML Semântico
- 🎬 YouTube Embed
- 📝 Formulários HTML
